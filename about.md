# Easy GDBot

Macro bot for Geometry Dash 2.2091 (.gdr2). Press Tab to open the menu (or use the pause menu button on mobile).

Features:
- Record / play macros (.gdr2) with frame fix, checkpoint fix, seed, 2P and platformer support
- Mega Hack replay import from the replays folder
- TPS bypass (240 - 20000), frame advance, speedhack, noclip, safe mode
- Hitboxes, hitbox trail, hitboxes on death, trajectory

Uses [GDReplayFormat](https://github.com/maxnut/GDReplayFormat). Frame stepper inspired by [OpenHack](https://github.com/Prevter/OpenHack) and physics stepping by [Click Between Frames](https://github.com/theyareonit/Click-Between-Frames).
